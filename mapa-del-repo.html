Mapa de Open MCT

Open MCT es como un tablero de mandos que se arma con piezas de Lego: la NASA lo usa para ver en una pantalla, en vivo y con gráficas, lo que sus naves y robots le van contando, y cualquiera puede enchufarle sus propios datos.

Este mapa explica cómo está construido por dentro y qué tendríamos que enchufarle para ver la telemetría de Percy (el rover Perseverance). Cada caja indica el archivo y la línea exacta del código donde ocurre, con el formato archivo:línea.

Cómo conectamos Percy

Nuestra fuente de datos más sencilla es nuestra propia simulación 3D de Perseverance: el rover ya sabe su velocidad, su rumbo y su posición. Más adelante podríamos cambiarla por datos públicos reales de la NASA sin tocar el resto.

  1. Decidir qué canales mostrar

    Por ejemplo: velocidad (m/s), rumbo (grados) e inclinación (grados). Cada canal será una línea en una gráfica.

  2. Hacer que la simulación “hable”

    Que el rover envíe varias veces por segundo un mensaje con la hora y sus valores, por ejemplo { utc: 1730000000000, velocidad: 1.8 }. Es el mismo formato que el dato de ejemplo del paso B6.

  3. Crear el plugin de Percy (pieza 1)

    Una receta que recibe openmct y registra las piezas 2 a 5, igual que hace el generador de ejemplo en example/generator/plugin.js:64 y example/generator/plugin.js:166.

  4. Registrar el tipo “canal de Percy” y la carpeta “Percy” (piezas 2 y 3)

    Con openmct.types.addType, openmct.objects.addRoot y openmct.objects.addProvider. Así aparece “Percy” en el árbol con sus canales.

  5. Ponerle a cada canal su ficha (pieza 4)

    Una lista telemetry.values con dos entradas: la hora (marcada como domain, eje X) y la medida (marcada como range, eje Y). Si la ficha va dentro del propio objeto, Open MCT la lee sola (src/api/telemetry/DefaultMetadataProvider.js:44).

  6. Escribir el “cartero” (pieza 5)

    Un proveedor con dos funciones: request devuelve los datos de un intervalo de tiempo y subscribe llama a la gráfica cada vez que llega un dato nuevo. Se registra con openmct.telemetry.addProvider.

  7. Enchufarlo antes de encender

    Añadir openmct.install(PercyPlugin()) junto a la línea index.html:104, antes de openmct.start() (index.html:240).

  8. Abrir un canal y mirar la gráfica

    Al hacer clic en “velocidad”, Open MCT recorre solo los pasos B3 a B9 y dibuja la línea. La tabla y la vista de último valor también funcionan sin código extra.

Para quien programe: esqueleto del plugin 
export default function PercyPlugin() {
  return function install(openmct) {
    openmct.types.addType('percy.canal', { name: 'Canal de Percy', cssClass: 'icon-telemetry' });

    openmct.objects.addRoot({ namespace: 'percy', key: 'rover' });
    openmct.objects.addProvider('percy', {
      get: (id) => Promise.resolve(id.key === 'rover'
        ? { identifier: id, name: 'Percy', type: 'folder',
            composition: [{ namespace: 'percy', key: 'velocidad' }] }
        : { identifier: id, name: 'Velocidad', type: 'percy.canal',
            telemetry: { values: [
              { key: 'utc', name: 'Hora', format: 'utc', hints: { domain: 1 } },
              { key: 'value', name: 'Velocidad', unit: 'm/s', hints: { range: 1 } }
            ] } })
    });

    openmct.telemetry.addProvider({
      supportsRequest: (o) => o.type === 'percy.canal',
      request: (o, { start, end }) => historial(o.identifier.key, start, end),
      supportsSubscribe: (o) => o.type === 'percy.canal',
      subscribe: (o, callback) => escuchar(o.identifier.key, callback) // devuelve "dejar de escuchar"
    });
  };
}

historial y escuchar serían las funciones que leen los datos de nuestra simulación.
